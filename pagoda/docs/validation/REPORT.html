金标准：Umpierre 2011 JAMA（PMID 21540423）人工纳入的 34 项 RCT · 阴性：同检索池随机 245 篇 · 方案见 PROTOCOL.md
执行摘要：合成测试集上的 97.5% 准确率在真实文献上不复现。 微调版默认阈值下灵敏度仅 47.1%（漏掉 18/34 篇真实试验），不满足初筛 ≥95% 要求； 基座零样本灵敏度 94.1% 接近达标但特异度仅 27.8%。 两模型排序能力相当（AUC 均 ≈ 0.74），差异全在默认工作点与概率尺度。 结论：当前形态均不可直接部署；基座 + 阈值重标定（t=0.36 → 97.1% 灵敏度）是唯一可立即使用的形态。

7. 根因分析

根因机制
分布偏移合成种子出自同一生成模板，风格单一；微调学到"模板匹配"而非"证据概念"，对真实措辞多样性泛化失败
温度重标定副作用留出集标定在合成分布上完成，整体左移概率尺度；真实分布上决策边界埋进阳性分布内部
任务定义错位初筛正确行为是"疑罪从有"（灵敏度优先），准确率目标在平衡合成集上奖励的是"敢拒绝"

8. 结论

❌ 微调版（现状）不可部署。漏诊率 52.9% 会使系统综述结论失效
⚠️ 基座零样本接近可用。t=0.36 时灵敏度 97.1%、工作量削减 20%，但人力节省有限
✅ 工程链路Rust 服务、A/B 并行评测、阈值扫描、真实金标准构建全部按方案工作——问题定位在数据与标定层面，而非推理引擎

10. 局限

  • 阳性 34 篇，灵敏度 CI 宽（±16pp）；结论方向明确但精密度有限
  • 阴性为"未最终纳入"而非"摘要级人工排除"，含少量全文阶段才排除的准阳性
  • 单一综述（T2DM 运动领域），外推其他专科需再验证
  • 评估在 CPU 模式 Rust 服务完成，吞吐数字不代表 GPU 部署

附：工程事实（本次验证顺带证实）

  • Rust 版 laya_server 连续 61 分钟、558 次推理零故障（279 篇 × 2 模型）
  • 单篇判定 12.6s 为双模型串行+共享 CPU 所致（单模型约 6s）；部署应一模型一实例
